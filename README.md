# Auto — Car Import Landing Page

A responsive landing page for a car import company specializing in vehicles from the USA to Ukraine.

**[Live Demo](https://romanmytsu.github.io/auto/)** · **[GitHub Repository](https://github.com/RomanMytsu/auto)**

## About the Project

Auto is a portfolio project built around a landing page for a company that helps customers select, purchase, ship, and import vehicles from the United States to Ukraine.

The website presents the company's services, explains the import process, showcases selected vehicles, and provides contact information and a consultation request form.

The project was originally built with WordPress and published as a static website using Simply Static and GitHub Pages.

## Features

- Responsive landing page layout
- Hero section with a call to action
- Company services and vehicle import process
- Benefits and statistics section
- Car showcase carousel
- Contact information and social media links
- Consultation request form UI
- Privacy policy page
- CSS animations and interactive elements

## Tech Stack

- **WordPress** — original content management system
- **HTML5** — semantic page structure
- **CSS3** — styling and responsive layouts
- **JavaScript** — client-side interactions
- **Slick Carousel** — car showcase slider
- **WOW.js** — scroll-triggered animations
- **Animate.css** — CSS animations
- **Contact Form 7** — original WordPress contact form
- **Simply Static** — static site generation
- **GitHub Pages** — deployment and hosting

## Deployment

The website is hosted on GitHub Pages as a static export of the original WordPress project.

The repository contains the generated website files rather than a complete, independently installable WordPress environment.

## Limitations

GitHub Pages does not execute PHP or provide a WordPress database. Therefore, WordPress administration and server-side functionality are unavailable in the deployed version.

The contact form requires a working backend to process submissions and should not be considered functional unless an external form service or backend has been configured.
